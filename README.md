# KLIPY IOS and Android App: Create and Play Mini-Games

<img width="2000" height="1000" alt="Games for Email " src="https://github.com/user-attachments/assets/9e3839a3-f3d8-438e-9615-3cb4d0ac08bb" />


KLIPY is a mobile app for creating, playing and sharing AI-generated mini-games. It works like TikTok, except every item in the feed is a playable game instead of a video. Anyone can describe an idea in plain language and get a working game in a few minutes, using the media, music and other libraries built into the app, with no coding and no cost. Players can scroll an endless feed and try as many games as they want, remix any game by telling the AI what to change, and compete for the top spot on the leaderboards of score-based games. Creators can also enter monthly in-app game jams for a chance to win prizes. Beyond games, KLIPY offers millions of reaction GIFs, stickers and clips, which you can search with highly relevant results and send on any platform once the KLIPY keyboard is set up.


## Features

- **Endless game feed.** Scroll through games made by the community and play as many as you like.
- **AI game creation.** Describe an idea and the AI builds a playable game in a few minutes. It is free, and you can use the built-in libraries of media and music.
- **Remix.** Describe changes to any game and the AI creates your own version of it.
- **Leaderboards.** Score-based games have leaderboards, so you can compete for the top spot.
- **Game jams.** Monthly in-app jams where creators build games and win prizes.
- **Reactions.** Search millions of GIFs, stickers and clips. Set up the KLIPY keyboard once to share them on any platform.
